# got-rl-surgery quickstart
1. git clone <repo> && cd got-rl-surgery
2. conda env create -f env.yaml
3. conda activate got-rl-surgery
4. no pip install -e . needed
5. place data inside data/
6. python detectors/train_yolov8_seg.py
7. explore other detectors/ scripts
8. expand agent/ for RL+GoT
9. run eval/ to benchmark
